# 🎮 Steam Games Price Prediction

> 💡 A Machine Learning project to predict the price of Steam games.

### 🚀 Tech Stack

**Python • Pandas • NumPy • Scikit-learn • Matplotlib • Joblib**

### 🤖 Model

**Random Forest Regression**

The model is trained using Steam game data and evaluated using:

* 📊 MAE
* 📈 RMSE
* 🎯 R² Score

### 🔄 Workflow

`Dataset → Preprocessing → Train/Test Split → Random Forest → Prediction → Evaluation`
